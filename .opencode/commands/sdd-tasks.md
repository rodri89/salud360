A partir de specs/$1/spec.md y specs/$1/plan.md, generá specs/$1/tasks.md siguiendo el formato de la skill sdd:
- Tareas pequeñas (máx. 20-30 min cada una), en orden de dependencia (modelo → base → datos → interfaz).
- Cada una con los RF que cubre y una línea "Hecho cuando:" verificable (test o comando concreto).
- Checkboxes.
- Intentá que no sean más de 10: si salen más, proponé dividir la spec.
